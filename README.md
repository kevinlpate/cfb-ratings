# Pace & Pate Analytics — College Football

2026 college football ratings, this week's win probabilities (with Kalshi and Vegas comparisons), season projections, PnP Resume rankings, player values, team profiles and a backtest.
Live site: https://kevinlpate.github.io/cfb-ratings/

The page (`index.html`, `js/`) reads CSV files in `data/`, refreshed every morning during the season.
Projections, not betting advice.
